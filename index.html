Level 1 guide

Your First PR

Fill in your details and every command below fills itself in for you. Copy, paste, done.

≈ 30 minutes.
Promise.

your details

That doesn't look like a GitHub username. Letters, numbers and single hyphens only.

contributors/your-username.json

your shortcuts

Merged? Show it off on your GitHub profile README:

[![Open Source BYTE 2K26 contributor](https://img.shields.io/badge/Open_Source_BYTE_2K26-contributor-e3341e?labelColor=16213e)](https://thebyteclubnie.github.io/Open-Source_BYTE_2K26/)

  1. Set up Git (once per laptop)

    Check whether you already have it. If you see a version number, you're set.

    git --version
    Don't have Git yet?
    • Windows: download it from git-scm.com and keep every default option.
    • Mac: run xcode-select --install in Terminal.
    • Linux: run sudo apt install git.

    Can't install anything? Open the project in GitHub Codespaces. It's VS Code and Git in your browser, free for students.

    Then tell Git who you are, or your first commit will fail. Use the email on your GitHub account so commits show up on your profile.

    git config --global user.name "Your Name"git config --global user.email "you@example.com"

  2. Fork the repo

    This makes your own copy on GitHub that you're allowed to change.

    Fork it on GitHub ↗

  3. Clone your fork

    Download your copy to your laptop.

    git clone https://github.com/your-username/Open-Source_BYTE_2K26.gitcd Open-Source_BYTE_2K26

  4. Make a branch

    Keep your change separate from main.

    git checkout -b add-your-username

  5. Add your file

    Create contributors/your-username.json and paste in your file from the details card.

  6. Commit and push

    Save your change with a message, then send it to your fork.

    git add contributors/your-username.jsongit commit -m "Add your-username to contributors"git push origin add-your-username

  7. Open the pull request

    Go to your fork on GitHub and click Compare & pull request. A bot checks your file and merges it, and your face shows up on this page.

    Open a pull request ↗

  1. Open the new file page

    This button opens GitHub in a new tab with your file name and contents already filled in. Keep this page open for the next steps.

    Create my file on GitHub ↗

    First type your GitHub username in the details card, so the file gets your name.

  2. Fork when asked

    GitHub may say you can't edit this repo directly. Click Fork this repository. If the file name or the text box is empty after that, copy both from your details card: the name is contributors/your-username.json and the text is in the dark box with the copy button.

  3. Propose the change

    Click Commit changes…, then Propose changes.

  4. Open the pull request

    Click Create pull request. A bot checks your file and merges it. Try the terminal way at Level 3, you'll need it there.

Merged? Go tick off Level 1 on the journey ↑

Cheat sheet

Git, Decoded

The commands you'll actually use, in plain English. Type what you want to do.

Bookmark this.
Seriously ✱

Get the project on your laptop

git clone https://github.com/your-username/Open-Source_BYTE_2K26.git

Downloads your fork. You only do this once.

See what you changed

git statusgit diff

status lists changed files, diff shows the exact lines.

Start something new

git switch -c my-change

Makes a new branch and moves you onto it. One branch per pull request.

Save your work

git add .git commit -m "Describe what you changed"

add picks the changes, commit saves them with a message.

Send it to GitHub

git push origin my-change

Uploads your branch to your fork. Then open a pull request on GitHub.

Get the club's latest changes

git remote add upstream https://github.com/TheBYTEClubNIE/Open-Source_BYTE_2K26.gitgit pull upstream main

The first line is a one-time setup. After that, just run the second line.

Throw away changes to a file

git restore path/to/file

Puts the file back to your last commit. Careful: the changes are gone for good.

Undo the last commit, keep the work

git reset --soft HEAD~1

Un-saves the commit but keeps your changes, so you can fix and commit again.

Fix the last commit message

git commit --amend -m "Better message"

Only before you push. After pushing, just make a new commit instead.

See the history

git log --oneline

One line per commit, newest first. Press q to exit.

    Ask a question ↓
    I've never used Git. Can I still join?

    Yes. Levels 0 and 1 assume zero experience. If installing Git feels scary, use the Browser only route for your first PR and learn the terminal later.

    Do I need to be good at coding?

    No. Levels 0 to 2 are mostly writing and editing text. Code starts at Level 3, and by then you'll know the workflow.

    My push says "permission denied".

    You're pushing to the club's repo instead of your fork. Fork first, clone your fork, then push there.

    My fork is behind. What do I do?

    On your fork's GitHub page, click Sync fork, then run git pull on your laptop.

    I made a mistake in my pull request.

    No need to close it. Fix the file, commit, and push to the same branch. Your PR updates itself.

    What's a merge conflict, and how do I fix it?

    Two people changed the same lines. Git marks both versions in the file with <<<<<<< and >>>>>>>. Keep the right lines, delete the markers, then commit. You'll practise this at Level 3.

    Can I make more than one Level 1 PR?

    One per person. Your contributor file is yours to keep. After that, move on to Level 2 issues.

    How long until my PR is reviewed?

    Level 1 PRs are checked and merged automatically. Everything else gets a reply from a maintainer within 48 hours.
